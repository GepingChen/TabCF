# interv_mean

This public release keeps:

- `pipeline/`: manifest-driven interventional-mean benchmark pipeline used for the paper-facing comparisons.
- `manifests/`: source presets used to generate benchmark manifests.
- `tests/`: lightweight tests relevant to the shipped public code.

The shipped mean-benchmark artifacts live at:

- `artifacts/aggregated_csv/interv_mean/mean_benchmark_results.csv`
- `artifacts/paper_figures/original/interv_mean/mean_benchmark_figure.pdf`

Scheduler helpers, temporary explorations, and large generated IO trees are intentionally excluded here.
